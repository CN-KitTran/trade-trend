# 证据冻结与查证边界

候选后按 case 定向取证，不做泛新闻扫描。优先级：官方政策/监管/交易所/公司披露，权威统计与行业机构，最后才是可信二手材料。搜索结果摘要和聚合页不能单独成为正式证据。

每条冻结证据至少保存：稳定 `evidence_id`、原始 URI、来源层级、发布时间、抓取时间、内容哈希、最小事实抽取、适用主题/命题、支持或反对方向，以及 `EXTERNAL_UNTRUSTED_CONTENT_ISOLATED` 信任边界。不得保存鉴权信息。

证据包不得为空。每个进入正式判断的 case 至少包含：市场结构证据、适用的市场状态/板块角色证据、产业事实查证结果、反对证据或合理替代解释，以及事实公布与市场定价时间线。机会还必须给出下一验证与失效条件；风险必须给出风险解除条件。证据充分、重复或冲突暂不可解决时停止；不以文章数为目标。

查证缺项时先定向补差，不得用空数组或“无外部事实可引用”绕过。补查后仍未找到新增直接事实，必须冻结查证范围、来源和截止时间，并显式记录 `NO_NEW_DIRECT_FACT_FOUND`。它可以用于区分“产业没有恶化”与“市场/风格风险”，但不能伪装成已获得产业确认。

证据要求随命题类型变化：

- 产业驱动机会需要直接产业事实与反证；
- 环境驱动机会需要完整市场状态、资金迁移和板块承接证据，并查证产业事实是否限制持续性；
- 市场/风格风险可在没有产业恶化时成立，但必须有多日市场结构、环境不利和资金流出/关注度恶化证据；
- 产业风险不能只用价格下跌证明。

市场结构证据日期不得晚于 D；外部事实 `published_at` 不得晚于盘前 `information_cutoff`。纠错只能复用原证据包。

## 当前实现限制

自动采集器、缺项补查器、原始正文快照与 `content_hash` 的逐字互锁尚未实现。当前 ledger gate 能验证 evidence artifact 自身不可变、来源字段、双截止、信任边界以及所有 row/case 引用是否存在，但尚未机械验证每个 case 的查证覆盖率，也不能仅凭手工填写的 URI/哈希证明外部事实真实。因此：

- `validate_outputs.py --kind themes` 的 PASS 只是结构与权限 PASS；
- `update_ledger.py` 的 PASS 增加引用集合与截止对账，仍不是外部事实真实性验收；
- 在可信采集与快照互锁完成前，外部 evidence 只能用于 INTERNAL_GATE 测试，不得据此发布正式结论。
