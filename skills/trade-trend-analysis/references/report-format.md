# 报告投影

日报只从 ledger 的 `report_projection` 和逐主题已校验字段渲染，不读取新事实。

固定顺序：市场现在在交易什么、今日结论、重点机会、重点风险、继续观察；再按需显示其他有效结论、撤出/失效/复核失败、候选变化和数据限制。独立安全提醒生命周期尚未实现，非空 alert 投影必须失败而不是渲染。

“市场现在在交易什么”只用 3—5 句话说明市场状态、风险偏好、主要资金迁移、持续阶段和关键矛盾，不写成宏观长文。

重点板块必须用简短自然语言交代：当前市场角色、主要驱动、市场结构、产业支持与反证、是否已定价、阶段/剩余空间和失效或解除条件。风险必须明确是产业风险还是市场/风格风险；不得用“基本面没有恶化”删除已被市场结构确认的风险，也不得把防御承接误写成产业景气改善。

`FOCUS` 展开，`BRIEF` 一行，`LEDGER_ONLY` 不入正文。路由为 BRIEF 的 FORMING 只进入继续观察。普通感知 WATCH 完整保存在 `sensing.json`，但因尚未经过候选后判断和报告路由，Markdown 只显示精确数量摘要而不逐项倾倒；这不会删除或截断感知记录。正文没有可展示对象时只能写“本栏无需要展示的结论”，不能把台账中的 `LEDGER_ONLY` 误写成市场不存在机会/风险。`CARRIED_FORWARD` 设计语义仍是“沿用上次已校验结论；本次复核失败”，但当前实现尚未具备安全承接，输入会直接失败关闭。

当前 renderer 始终先写 ledger 同目录 `preview.md`。`INTERNAL_GATE` 传 `--vault-root` 后还会把完全相同的 Markdown 原子写入 `investment/trend/YYYY-MM/Www/YYYY-MM-DD-板块扫描.md`；内容相同幂等，不同则拒绝覆盖。Vault 文件只是 `VALIDATED_NOT_PUBLISHED` 的 Obsidian 阅读副本，必须保留早稿/限制标记；SHADOW 不得写 Vault，OFFICIAL 发布器仍未启用。
